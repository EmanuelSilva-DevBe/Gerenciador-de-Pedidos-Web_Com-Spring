# Gerenciador-de-Pedidos-Web_Com-Spring
Projeto pessoal desenvolvido com foco em estudos de Desenvolvimento Web em Java utilizando o Spring Framework.
A aplicação utiliza Hibernate como ORM para mapeamento objeto-relacional e PostgreSQL como banco de dados.

A arquitetura foi estruturada no padrão MVC, promovendo melhor organização, manutenção e separação de responsabilidades no código.
No front-end, foram utilizadas páginas em HTML integradas ao back-end por meio do Thymeleaf, com o uso do Bootstrap para estilização e responsividade, tornando a interface mais dinâmica e amigável ao usuário.

Também foi adotado o padrão DTO para transferência de dados entre as camadas da aplicação, garantindo maior segurança, organização e desacoplamento entre o domínio e a camada de apresentação.
